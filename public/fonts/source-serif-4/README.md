# Source Serif 4

Unmodified WOFF2 fonts from Adobe's [Source Serif release 4.005R](https://github.com/adobe-fonts/source-serif/tree/4.005R/WOFF2/TTF). Regular, italic, semibold, and semibold italic cover the reader's provider-supplied marks. The complete upstream copyright notice and SIL Open Font License 1.1 are retained in [LICENSE.md](LICENSE.md), which is also included in the built site's public assets.

Fonts load from the same origin. No font CDN, new package dependency, or runtime external request is required.
